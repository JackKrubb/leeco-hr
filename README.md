# LEECO HR

เว็บลงเวลาเข้า-ออกงาน (ถ่ายรูปยืนยันตัวตน) + ปฏิทินวันหยุด + รายงานหลังบ้านของ LEECO
Next.js 16 (static export) · Supabase (Postgres) · Tailwind CSS 4 · โฮสต์บน GitHub Pages

**เว็บ:** https://jackkrubb.github.io/leeco-hr/

## มีอะไรบ้าง

**หน้าลงเวลา (พนักงาน — ไม่ต้องเข้าสู่ระบบ)**
- เปิดผ่าน “ลิงก์ลงเวลา” ที่ HR ส่งให้ (มีรหัสลับในลิงก์) — เปิดครั้งเดียว เครื่องจำไว้ · คนที่ไม่มีลิงก์จะไม่เห็นรายชื่อ
- รายชื่อพนักงานแยกตามฝ่าย ค้นหาได้ กรอง “ยังไม่เข้า / อยู่ในงาน / ออกแล้ว”
- แตะชื่อตัวเอง → **ต้องถ่ายรูปหน้าตัวเองก่อน** → กด “เข้างาน” หรือ “ออกงาน”
- เวลาใช้ของเซิร์ฟเวอร์ (Asia/Bangkok) ไม่ใช่เวลาบนเครื่อง
- ปฏิทินวันหยุดของบริษัท

**กติกาเวลา (ตั้งค่าได้)**
- เวลาทำงาน 08:00–17:00 น. วันทำงาน จ–ส
- **มาสาย** = เข้าหลัง 08:01 (สายเกิน 1 นาที) นับนาทีจาก 08:00
- **กลับก่อน** = ออกก่อน 17:00 นับนาทีที่ออกก่อน
- วันหยุดบริษัท / วันที่ไม่ใช่วันทำงาน ไม่นับสาย-กลับก่อน · OT ยังไม่คิด

**รูปถ่าย**
- เก็บเป็นรูปเล็ก 240×240 JPEG (~10–20 KB)
- ลบอัตโนมัติทุกวันตี 3 **เฉพาะ** รูปที่อายุเกิน 30 วัน **และ** HR กด “ยืนยันว่าตรวจรีพอร์ตเดือนนี้แล้ว” ในรายงานรายเดือนของเดือนนั้น
- เดือนที่ยังไม่ได้ตรวจ รูปจะไม่ถูกลบเด็ดขาด (หน้ารายงานรายวันจะเตือน)

**หลังบ้าน (HR / แอดมิน — เข้าด้วยรหัส + PIN)**
- รายงานรายวัน: มา / สาย / กลับก่อน / ขาด พร้อมรูปเข้า-ออก แยกตามฝ่าย ดาวน์โหลด Excel
- รายงานรายเดือน: สรุปรายคน + ตารางสีทั้งเดือน + ปุ่มยืนยันการตรวจรีพอร์ต
- ช่วงวันที่ / แก้ไขเวลาย้อนหลังพร้อมเหตุผล
- พนักงาน: นำเข้าจาก Excel (ไฟล์รายชื่อแบบเดิมของ HR ใช้ได้เลย), เพิ่ม/แก้ไข
- วันหยุด: นำเข้าจาก Excel หรือเพิ่มทีละวัน
- ตั้งค่า: ลิงก์ลงเวลา (คัดลอก / เปลี่ยนใหม่), เวลาทำงาน, GPS

## โครงสร้าง

```
supabase/migrations/       ตาราง + ฟังก์ชัน hr_* (รันตามลำดับ 001 → 005)
src/app/page.tsx           หน้าลงเวลา (kiosk)
src/app/admin/             หลังบ้าน
src/lib/api.ts             เรียกฟังก์ชัน hr_* จากเบราว์เซอร์
src/lib/excel/             ตัวอ่าน Excel (ทำงานในเบราว์เซอร์)
.github/workflows/pages.yml  build + deploy ขึ้น GitHub Pages ทุกครั้งที่ push main
```

### ความปลอดภัย
- เว็บเป็นไฟล์ static ทั้งหมด เรียกฐานข้อมูลผ่านฟังก์ชัน `hr_*` เท่านั้น — ตารางเปิด RLS และไม่ให้สิทธิ์อ่านตรง
- หน้าลงเวลาต้องมี kiosk key (อยู่ในลิงก์), หลังบ้านต้องมี session token จากการเข้าสู่ระบบด้วย PIN (เก็บใน localStorage, ฐานข้อมูลเก็บแค่ hash)
- ใช้แค่ publishable key ซึ่งเปิดเผยได้ (อยู่ใน `.env.production`) — **ห้ามใส่ service_role key**
- Supabase Security Advisor จะเตือน “SECURITY DEFINER function executable by anon” — เป็นไปตามที่ออกแบบ
- ถ้าลิงก์ลงเวลาหลุด: หลังบ้าน → ตั้งค่า → สร้างลิงก์ใหม่

## พัฒนา / Deploy

```bash
npm install
npm run dev        # http://localhost:3000/leeco-hr/
npm run build      # ได้โฟลเดอร์ out/
```

Deploy: push ขึ้น `main` แล้ว GitHub Actions จะ build และเผยแพร่ให้เอง
ตั้งค่าครั้งเดียว: repo → Settings → Pages → Source: **GitHub Actions**

ทดสอบตัวอ่านไฟล์: `npx tsx scripts/try-import.mts <file.xlsx> [ลำดับชีต]`

## ยังไม่มี
- OT, ใบลา (และหักวันลาออกจาก “ขาด”), กะทำงาน
- แจ้งเตือน LINE, สิทธิ์หัวหน้าแผนก
