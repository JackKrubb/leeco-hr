# LEECO HR

เว็บแอปลงเวลาเข้า-ออกงาน + ปฏิทินวันหยุดของ LEECO
Next.js 16 (App Router) · Supabase (Postgres) · Tailwind CSS 4 · ภาษาไทย

## ทำอะไรได้บ้าง (v0.1)

**พนักงาน** (มือถือ)
- เข้าระบบด้วย **รหัสพนักงาน + PIN** (ครั้งแรกบังคับเปลี่ยน PIN, ผิด 5 ครั้งล็อก 15 นาที)
- ปุ่ม **ลงเวลาเข้างาน / ออกงาน** — ใช้เวลาของเซิร์ฟเวอร์ (โซนเวลา Asia/Bangkok) ไม่ใช่เวลาบนมือถือ, เก็บพิกัด GPS ถ้าอนุญาต
- บอกว่า **มาสายกี่นาที** และวันนี้เป็นวันหยุดหรือไม่
- **ปฏิทินรายเดือน** แสดงวันหยุดราชการ / วันหยุดบริษัท / วันที่บริษัทไม่ทำงาน + จุดสีวันที่ตัวเองมาทำงาน/มาสาย
- ประวัติลงเวลา 14 วันล่าสุด

**กติกาเวลา (ตั้งค่าได้ในหน้า “ตั้งค่า”)**
- เวลาทำงาน 08:00–17:00 น. วันทำงาน จ–ส
- **มาสาย** = ลงเวลาเข้าหลัง 08:01 (สายเกิน 1 นาที) นับนาทีสายจาก 08:00
- **กลับก่อน** = ลงเวลาออกก่อน 17:00 นับนาทีที่ออกก่อน
- วันหยุดบริษัท / วันที่ไม่ใช่วันทำงาน ไม่นับสาย-กลับก่อน · OT ยังไม่คิด

**หลังบ้าน (HR / แอดมิน)**
- **รายงานรายวัน**: ใครมา / สาย / กลับก่อน / ขาด แยกตามฝ่าย กรองเฉพาะกลุ่มได้ เลือกวันที่ย้อนหลัง ดาวน์โหลด Excel
- **รายงานรายเดือน**: สรุปรายคน (วันทำงาน, มา, ขาด, สายกี่ครั้ง/กี่นาที, กลับก่อนกี่ครั้ง/กี่นาที, ไม่ลงเวลาออก) เรียงตามคนที่สายมากสุดได้ + ตารางสีพนักงาน × วันทั้งเดือน ดาวน์โหลด Excel
- **พนักงาน**: อัปโหลด Excel → ดูตัวอย่างและคำเตือนก่อนบันทึก → บันทึก (จับคู่คนเดิมจากรหัสหรือชื่อ-นามสกุล), สร้าง PIN แบบพิมพ์แจก, รีเซ็ต PIN, แก้ไข/เพิ่มทีละคน
- **วันหยุด**: อัปโหลด Excel ตารางวันหยุด (แทนที่ทั้งปีได้), เพิ่ม/ลบทีละวัน
- **ช่วงวันที่ / แก้ไขเวลา**: รายงานช่วงวันที่ใดก็ได้, HR แก้ไขเวลาย้อนหลังพร้อมเหตุผล
- **ตั้งค่า**: เวลาเข้า-เลิกงาน, นาทีผ่อนผัน, วันทำงาน (ค่าเริ่มต้น จ–ส), ตำแหน่ง GPS ของบริษัท + รัศมี, บังคับอยู่ในพื้นที่หรือไม่

### ไฟล์ Excel ที่รองรับ
- **รายชื่อพนักงานแบบเดิมของ HR** (ชีต “รายชื่อพนักงานทั้งหมดปัจจุบัน”) อัปโหลดได้ตรง ๆ — ระบบเข้าใจหัวแผนกที่คั่นระหว่างกลุ่ม, `,,` / `''` ที่แปลว่า “เหมือนข้างบน”, วันที่แบบ `6/3/67` (พ.ศ.), แถว “รวม N คน”
- หรือใช้แม่แบบ `public/templates/employees-template.xlsx`
- วันหยุด: `public/templates/holidays-2569.xlsx` (วันหยุดราชการ 2569 — **HR ต้องยืนยันว่าบริษัทหยุดวันไหนจริง**)
- **ไม่นำเข้าข้อมูลค่าจ้าง** (ค่าแรง, เงินเดือน, ค่าตำแหน่ง) — แอปลงเวลาไม่จำเป็นต้องใช้ และทุกคนที่เป็นแอดมินจะเห็น

ทดสอบตัวอ่านไฟล์จากเครื่อง: `npx tsx scripts/try-import.mts <file.xlsx> [ลำดับชีต]`

## โครงสร้าง

```
supabase/migrations/   ตาราง + ฟังก์ชัน hr_* (ทั้งหมดอยู่ในฐานข้อมูล)
src/lib/excel/         ตัวอ่าน Excel (ไม่ขึ้นกับ Next.js, ทดสอบแยกได้)
src/app/(employee)/    หน้าพนักงาน: ลงเวลา, ปฏิทิน
src/app/admin/         หลังบ้าน
src/app/actions/       Server Actions (เรียก hr_* ผ่าน Supabase)
```

### ความปลอดภัย
- ตารางทั้งหมดเปิด RLS และ **ไม่ได้ให้สิทธิ์ anon/authenticated อ่านตรง** — เว็บเรียกได้เฉพาะฟังก์ชัน `hr_*`
- ทุกฟังก์ชันรับ session token แล้วตรวจเองว่าเป็นใคร/เป็นแอดมินหรือไม่ (token เก็บใน cookie แบบ httpOnly, ในฐานข้อมูลเก็บแค่ hash)
- เพราะออกแบบแบบนี้ Supabase Security Advisor จะเตือน “SECURITY DEFINER function executable by anon” — เป็นไปตามที่ตั้งใจ
- ใช้แค่ publishable key — **ห้ามใส่ service_role key ในแอปนี้**
- PIN เก็บแบบ bcrypt

## ติดตั้ง

```bash
npm install
cp .env.example .env.local   # ใส่ SUPABASE_URL และ SUPABASE_PUBLISHABLE_KEY
npm run dev
```

ฐานข้อมูล: รันไฟล์ใน `supabase/migrations/` ตามลำดับ (001 → 002 → 003) (Supabase Dashboard → SQL Editor หรือ `supabase db push`)
ไฟล์ `..._hr_functions.sql` รันซ้ำได้ (ใช้ `create or replace`)

Deploy: Vercel → import repo → ใส่ env 2 ตัวเดียวกัน

บัญชีแอดมินเริ่มต้น: รหัส `ADMIN` (PIN แรกได้จากคนติดตั้ง ต้องเปลี่ยนตอนเข้าครั้งแรก) → เพิ่มสิทธิ์แอดมินให้ HR ตัวจริงได้ในหน้าแก้ไขพนักงาน

## ยังไม่มี (ไอเดียรอบถัดไป)
- ใบลา / อนุมัติลา และหักวันลาออกจาก “ขาด”
- กะทำงาน / เวลาเข้างานต่างกันตามแผนก, กะข้ามเที่ยงคืน
- คำนวณ OT
- ถ่ายรูปตอนลงเวลา หรือเครื่อง kiosk หน้าโรงงาน (สแกน QR)
- เข้าระบบด้วย LINE / แจ้งเตือน LINE ให้หัวหน้าเมื่อมีคนสาย
- สิทธิ์หัวหน้าแผนก (เห็นเฉพาะลูกทีม)
- PWA ติดตั้งบนหน้าจอมือถือ
